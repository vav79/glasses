# Скриншоты для статьи на Хабре

Задание для Claude Code · 02.11.2026

Нужно 20 скриншотов для статьи о том, как создавалось приложение: по 2–4 кадра на каждый этап истории, от первой версии 16 октября до нового интерфейса 2 ноября. Номер в таблице = имя файла = номер иллюстрации в статье.

Результат — в `docs/article/screens/`. Код приложения не менять.

## Общие правила

1. **Старые версии — рядом с текущей, не поверх.** Каждую историческую версию собирай во временном `git worktree` на нужном коммите. В копии временно добавь к `applicationId` суффикс `.history`, а к названию — « (история)». Эти правки — только в worktree, не коммитить. Так моя рабочая версия, её ключи, чаты и настройки не пострадают.
2. **Текущую версию для кадров 14–17 и 20 — тоже копией с суффиксом.** Там понадобятся демо-чаты и сброс первого запуска, в рабочей версии этого делать не нужно.
3. **Ключи** для копий — из моего `local.properties`, как обычно. На экранах ключ не должен быть виден даже частично.
4. **Никаких личных данных в кадре:** имён, адресов дома и работы, телефонов, почты, аккаунта Meta, реальной истории чатов, моих мест, личных фото на обоях. Всё — демо.
5. **Демо-содержимое — нейтральное и про путешествие**, на русском. Например: «Что посмотреть в Бангкоке за один день?», «Как сказать таксисту: в аэропорт Суварнабхуми?». Места в навигации — публичные: отель, рынок, храм Ват Арун. Если в сборке есть отладочная «Симуляция места» — поставь Бангкок.
6. **Строка состояния:** включи демо-режим SystemUI (часы 12:00, полный заряд, без уведомлений) и выключи после съёмки. Если Samsung его игнорирует — обрежь строку состояния при обработке, оригинал сохрани.
7. **Тема:** как была в каждой версии; у текущей — тёмная.
8. **Где нужны очки, собеседник или мои руки** (кадры 07, 08, 09, 10, 12, 18, 20) — подготовь экран и попроси меня сделать действие, дождись.
9. Проверь отладочную `ShowcaseActivity` — если она показывает экраны с демо-данными, используй её, где удобно.

## Формат

- Оригинал — PNG из `adb exec-out screencap -p`: `NN-имя.png`.
- Копия для статьи — JPEG шириной 1080 px, качество 90: `NN-имя.jpg`.
- Обзорный лист `overview.jpg` — все кадры мелко, с номерами, для быстрой проверки.
- `docs/article/screens/README.md` — таблица: номер, файл, подпись, с какой версии снят.

## После съёмки

1. Удали временные worktree и копии с суффиксом `.history` с телефона.
2. Выключи демо-режим строки состояния.
3. Убедись, что на телефоне стоит моя рабочая версия (`redesign` HEAD) и её данные на месте.
4. Закоммить только `docs/article/` отдельным коммитом.
5. Пришли отчёт: что снято, с какой версии, что не получилось и почему.

Сначала план — особенно как будешь собирать старые версии рядом с текущей.
