Сняты 02.11.2026 на Galaxy S25 Ultra по заданию `../SCREENSHOTS_TASK.md`. Номер = номер иллюстрации в статье.

- `NN-имя.jpg` — для статьи: снято `adb shell screencap`, ширина 1080 px, качество 90, строка состояния (96 px) срезана. Оригиналы PNG в репозиторий не входят: на них настоящая строка состояния (демо-режим SystemUI Samsung игнорирует).
- `overview.jpg` — все кадры мелко, с подписями.
