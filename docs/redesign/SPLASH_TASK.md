# Sputnik — AI для очков: стартовая заставка

Задание для Claude Code · 02.11.2026

Добавить при запуске видеозаставку: тёмно-серый фон со светом сверху справа, глянцевые чёрные очки с камерой в переднем торце у шарнира поворачиваются, по стёклам бегут блики, появляется серебряная надпись «Sputnik AI», затем очки и надпись растворяются, кадр уходит в чёрный.

Файлы — в `docs/redesign/splash/`:

| Путь | Что это |
| --- | --- |
| `sputnik_splash.mp4` | Ролик: 3,6 с, 1080 × 2400, 30 к/с, H.264 High@5.0, без звука, 1,5 МБ |
| `poster.jpg` | Кадр из середины — для проверки и превью |
| `source/` | 3D-сцена и скрипт рендера — на случай правок |

Ролик начинается с чёрного кадра и заканчивается чёрным — переход в чёрный фон приложения получается бесшовным.

## Что сделать

1. Положи ролик в `app/src/main/res/raw/sputnik_splash.mp4`.
2. Системная заставка Android 12+ (SplashScreen API) обязательна и показывается до первого кадра приложения. Настрой её так, чтобы она не спорила с роликом: фон `windowSplashScreenBackground` — `#000000`, иконка — новая иконка приложения (см. `ICON_TASK.md`). Держать системную заставку дольше необходимого не нужно.
3. Сразу после неё — полноэкранный ролик поверх чёрного фона:
   - масштаб «заполнить с обрезкой по центру» — ролик 20:9, на экранах других пропорций обрежутся только края, очки и надпись в центре;
   - без звука, без элементов управления, системные панели скрыты на время ролика;
   - если в проекте уже есть Media3 / ExoPlayer — используй его, если нет — хватит `VideoView` без новых зависимостей.
4. По окончании ролика — переход на следующий экран: при первом запуске — пользовательское соглашение, дальше — чат (по `REDESIGN.md`).
5. Касание экрана во время ролика — пропустить заставку.
6. Показывать ролик только при холодном запуске. При возврате из фона, повороте экрана и пересоздании Activity — не показывать.
7. Если в настройках Android отключены анимации (масштаб длительности анимации = 0) — пропускать ролик.
8. Инициализация приложения (подключение к очкам, загрузка настроек) идёт параллельно с роликом и не ждёт его окончания.
9. Если ролик не удалось воспроизвести (ошибка декодера) — сразу переходить дальше, без сообщения об ошибке.

Проверь на телефоне: холодный запуск, повторный запуск из недавних, пропуск касанием, первый запуск (после ролика — соглашение), отключённые анимации.

Сделай отдельным коммитом. Если заставка конфликтует с этапами плана из `PLAN.md` — встрой её в тот этап, где меняется запуск приложения, и скажи об этом.
