# Sputnik — AI для очков: замена иконки запуска

Задание для Claude Code · 02.11.2026

Небольшая самостоятельная задача: заменить иконку приложения на новую — вариант «Глянец». От переработки интерфейса (`REDESIGN.md`) не зависит. Сделай отдельным коммитом в текущей рабочей ветке.

Все файлы — в `docs/redesign/icon/`:

| Путь | Что это |
| --- | --- |
| `res/mipmap-anydpi-v26/ic_launcher.xml`, `ic_launcher_round.xml` | Адаптивная иконка: фон, передний слой, монохромный слой |
| `res/mipmap-*/ic_launcher_background.png` | Фон, 108dp, пять плотностей |
| `res/mipmap-*/ic_launcher_foreground.png` | Очки с отражением, 108dp, в безопасной зоне 66dp |
| `res/mipmap-*/ic_launcher_monochrome.png` | Силуэт для тематических иконок Android 13+ |
| `res/mipmap-*/ic_launcher.png`, `ic_launcher_round.png` | Обычная и круглая иконки для Android ниже 8.0 |
| `playstore/ic_launcher-playstore.png` | 512 × 512 для магазина — в сборку не включать |
| `source/*.svg` | Исходники всех слоёв — на случай правок |
| `preview.png` | Как иконка выглядит: квадрат, круг, тематическая, мелкие размеры |

## Что сделать

1. Посмотри, как сейчас подключена иконка: `android:icon` и `android:roundIcon` в манифесте, какие файлы `ic_launcher*` лежат в `app/src/main/res` (в `mipmap-*` и `drawable*`), какой `minSdk`.
2. Скопируй содержимое `docs/redesign/icon/res/` в `app/src/main/res/` с заменой одноимённых файлов.
3. Удали старые файлы иконки, которые больше не используются: например, `drawable/ic_launcher_foreground.xml`, `drawable/ic_launcher_background.xml`, старые `.webp` с теми же именами в `mipmap-*` — два файла с одним именем и разными расширениями в одной папке не соберутся. Перед удалением убедись по поиску, что на них нигде нет ссылок, кроме иконки.
4. Если `minSdk` 26 или выше — `ic_launcher.png` и `ic_launcher_round.png` из `mipmap-*dpi` можно не копировать: они нужны только старым версиям Android.
5. Проверь, что манифест ссылается на `@mipmap/ic_launcher` и `@mipmap/ic_launcher_round`, а подпись под иконкой — «Sputnik» (как в `REDESIGN.md`, раздел «Общий стиль»).
6. Собери и установи. Проверь иконку на рабочем столе, в списке приложений, в настройках и в списке недавних. На Android 13+ включи тематические иконки и проверь монохромный вариант.

Если формат существующих ресурсов отличается (например, иконка задана векторным XML) — не подгоняй новую под старый формат, а замени целиком на файлы из `docs/redesign/icon/res/`. Если что-то мешает замене — спроси.
