**Важно при подготовке плана:** сначала составь полный перечень всех уже реализованных функций и настроек — по коду, `CLAUDE.md` и `docs/BACKLOG.md`. Ни одна не должна потеряться при переносе: в таблице соответствия у каждой указано новое место. Если для функции или настройки в новой структуре места нет — вынеси её в вопросы ко мне, не удаляй молча.

1. Изучи проект: стек, структура модулей, навигация, экраны, хранение данных. Отдельно — как сейчас работают подключение очков, вызовы API нейросетей, хранение ключей и умения (навигация, переводчик, инженер и другие).
2. Составь таблицу соответствия: что есть сейчас → куда переходит в новой структуре; что появляется впервые; что убираем.
3. Предложи план переноса по этапам. Каждый этап заканчивается собираемой рабочей версией, которую можно поставить на телефон и проверить.
4. Задай вопросы, без которых не можешь начать, и отметь технические риски — особенно по разделам «Открытые вопросы» и «Технические моменты для проверки».

Предлагаемый порядок этапов (поправь, если по коду выходит иначе): каркас (тема, навигация, шапка, боковое меню) → чат и ввод → первый запуск (соглашение) и ключи → умения и перевод → медиа и календарь → экран «Очки» → настройки.

## Общий стиль

Минимализм в духе современных ИИ-чатов (Meta AI, Claude): одна главная поверхность — чат, всё остальное на втором плане.

**Название приложения:** «Sputnik — AI для очков». Под иконкой в Android — «Sputnik» (длинное имя там обрежется); полное — в README, магазине, «О приложении» и пользовательском соглашении.

- Тема по умолчанию тёмная; в настройках — светлая или системная
- Язык интерфейса — русский и английский, все строки в ресурсах
- Масштаб шрифта — 80 / 90 / 100 / 110 / 120 %, применяется ко всему приложению
- Акцентный цвет включённого состояния (кнопка перевода) — зелёный, читается в обеих темах

## Первый запуск: пользовательское соглашение

Самый первый экран — до выбора модели. Без принятия соглашения приложение дальше не запускается.

- Заголовок «Пользовательское соглашение», ниже — текст с прокруткой. Полный текст — в разделе «Приложение: текст пользовательского соглашения» в конце документа
- Внизу, закреплено: галочка «Я прочитал(а) соглашение, понимаю риски из раздела 3 и принимаю их на себя»
- Кнопка «Принять и продолжить» — активна только после галочки. Кнопка «Выйти» закрывает приложение
- После принятия — экран выбора модели
- На устройстве сохраняется версия принятого соглашения и дата. Вышла новая версия — при следующем запуске экран показывается снова
- Текст соглашения доступен позже в Настройки → О приложении
- В английском интерфейсе — перевод соглашения с пометкой, что при расхождениях действует русский текст

**Сверь с кодом:** соглашение утверждает, что ключи и данные хранятся только на устройстве и не передаются разработчику, а аналитики нет. Если в приложении есть аналитика, отчёты о сбоях или любой сервер разработчика — сообщи: текст нужно будет поправить.

Показывается при первом запуске, сразу после принятия соглашения. Дальше приложение открывается сразу в чат, а модели и ключи меняются в Настройки → ИИ-ассистенты.

Список сверху вниз:

| Модель | По нажатию |
| --- | --- |
| Claude | Окно ввода API-ключа |
| DeepSeek | Окно ввода API-ключа |
| ChatGPT | «В разработке» |
| GigaChat | «В разработке» |

- Ключ проверяется тестовым запросом сразу при вводе; результат — понятным сообщением

- Конкретную модель внутри провайдера не выбираем

Под списком — предупреждение и кнопка «Пропустить». Текст предупреждения:

> Без API-ключа функции ИИ будут недоступны. Останутся функции подключённых очков. Ключ можно добавить позже в настройках.

## Главный экран

При открытии приложения — сразу чат с ИИ, без стартовых меню.

**Шапка, слева направо:**

- ☰ — открывает боковое меню
- По центру — чип активного профиля (иконка + название + ▾). Тап открывает быстрый выбор профиля. Без профиля — «Обычный чат»
- Рядом с чипом — круглая кнопка перевода. Выключено: тонкий контур, приглушённая иконка. Включено: зелёная заливка. Доступна и без профиля. Скрывается, когда выбрано умение «Переводчик»
- Иконка очков с процентом заряда — тап открывает экран «Очки»
- ⋮ — меню чата (расположение — см. «Открытые вопросы»)

**Лента чата:**

- Всё, что озвучено, дублируется текстом в чате
- При смене профиля или включении/выключении перевода в ленту вставляется тонкий разделитель, например «— Профиль: Инженер · перевод вкл —»

**Поле ввода внизу — три способа:**

1. Текст
2. Голос — по умолчанию через устройство ввода, подключённое сейчас (очки, гарнитура или телефон). Источник меняется в настройках
3. Камера — только камера телефона или галерея. Фото с очков делается физической кнопкой на очках, не из приложения

**Вывод ответа:**

- Подключено устройство вывода (очки или гарнитура) — ответ озвучивается в него и дублируется текстом
- Ничего не подключено — только текст в чате

**Меню ⋮ → «Удалить чат»** — полное удаление истории. Перед удалением — подтверждение с названием чата:

> **Удалить чат «‹название›»?** Вся переписка будет удалена. Восстановить её будет нельзя. [Отмена] [Удалить]

Кнопка «Удалить» — красная.

## Боковое меню

Открывается кнопкой ☰. Образец компоновки — боковое меню приложения Meta AI, стиль — «Классика» (см. выше и макет). Три зоны:

**Верх:**

- Поиск по чатам — самая верхняя строка
- Новый чат — начинает новую ветку разговора
- Медиа
- Умения
- Календарь
- Очки — экран настроек подключённых очков (тот же, что по иконке в шапке)

**Середина — «Чаты»:**

- Последние 7 чатов + кнопка «Показать все»
- Значок очков у чата, начатого с очков
- Синяя точка у чата с непрочитанным ответом

**Низ (закреплено):**

- 🔔 Оповещения — пока только кнопка, функционал позже
- ⚙️ Настройки
- Справа — чип активной модели с индикатором доступности (см. «Визуальный стиль»)

## Умения и Переводчик

Все существующие функции (навигация, переводчик, инженер и т. д.) переезжают в раздел «Умения». Активен один профиль; Переводчик добавляется к нему отдельной кнопкой.

**Раздел «Умения»:**

- У каждого умения переключатель вкл/выкл и вход в настройки
- У профиля — свой системный промпт, который подставляется перед каждым запросом. Остальные настройки профилей — позже
- Выбранный профиль показывается в шапке главного экрана

**Профили:** Путешественник, Исследователь, Строитель / Инженер, Разработчик.

**Медиа с очков:**

- Профиль не выбран — фото и видео с очков просто сохраняются в «Медиа». Анализ — вручную, прикрепив файл из галереи в чат
- Профиль активен — фото и видео с очков сразу уходят ИИ на анализ под этот профиль
- Результат анализа пишется в текущий чат, без отдельных окон

**Переводчик:**

- Два режима: кнопка перевода в шапке, которая добавляется к любому профилю, и отдельное умение «Переводчик», выбираемое в чипе как профиль. При выборе умения кнопка перевода в шапке пропадает
- Речь собеседника (с микрофона очков или гарнитуры) переводится синхронно — голосом в устройство вывода и текстом в чат
- Моя речь переводится только текстом на экране в чате, не озвучивается
- У сообщения с переводом моей речи — кнопка «Показать»: текст во весь экран крупным шрифтом, развёрнутый к собеседнику напротив

**Настройки умения «Переводчик»:**

- Определить язык собеседника — переключатель: язык определяется автоматически по его речи, без ручного выбора
- Язык страны пребывания — с какого переводим, когда автоопределение выключено
- Перевод — на мой язык из региональных настроек
- Страна пребывания определяется по геолокации телефона. От неё зависят местная валюта для пересчёта цен и навигация: где Яндекс Карты не работают (например, в Таиланде), по умолчанию включаются Google Карты
- Моя валюта и выбранный сервис навигации подтягиваются из региональных настроек

## Медиа и Календарь

**Медиа:**

- Фото и видео, снятые очками
- Фото и видео, отправленные в чат
- Из «Медиа» файл можно прикрепить в чат для анализа

**Календарь:**

- По умолчанию события пишутся в календарь телефона
- Добавлять события можно через ИИ прямо из чата
- Google Календарь — опционально, при подключении соответствующего умения

## Экран «Очки»

Открывается из бокового меню и по иконке очков в шапке. Состав пока частичный — будет дополняться.

- Вверху по центру — стилизованное изображение очков: натуральный вид с намёком на встроенный ИИ. Например, мягкое свечение у камеры или на дужке, которое «дышит», когда очки подключены, и гаснет, когда нет. Форма обобщённая, без логотипов Ray-Ban и Meta
- Ниже — подключить / отключить очки
- Индикатор подключения и уровня заряда
- Включение и отключение жестов на дужке

## Настройки

Открываются кнопкой ⚙️ внизу бокового меню. Образец компоновки — экран настроек Meta AI. Пункты сверху вниз:

1. **Язык** — русский / английский (язык интерфейса)
2. **Тема** — тёмная / светлая / системная
3. **Размер шрифта** — 80 / 90 / 100 / 110 / 120 %
4. **ИИ-ассистенты** — список подключённых моделей, добавление и смена ключей. Тап по ассистенту — назначение ролей: текст, фото, видео, аудио. Если ключей несколько, каждая роль закрепляется за одной моделью
5. **Расходы по API** — отдельно по каждой модели. Считаются по количеству токенов из ответов API × цена; это оценка, точный баланс — в кабинете провайдера
6. **Личные** — стиль общения: промпт, который применяется только к ответам, озвучиваемым голосом. На ответы на вопросы, набранные текстом, не влияет
7. **Региональные** — мой язык (на него переводит Переводчик) и моя валюта (в неё ИИ пересчитывает цены из валюты страны пребывания)
8. **Навигация** — сервис для Путешественника: Яндекс Карты или Google Карты. Если в стране пребывания Яндекс Карты не работают, по умолчанию — Google
9. **О приложении** — версия, дата сборки, разработчик, текст пользовательского соглашения

## Технические моменты для проверки

Проверь по актуальной документации и коду, результат — в ответе вместе с планом.

- [ ] **Кнопка камеры на очках** — попадает ли снятое ею фото в Sputnik через Meta Wearables Device Access Toolkit, или только в приложение Meta AI. Если нет — какая есть альтернатива

- [ ] **Курсы валют** — модель актуальных курсов не знает: нужен внешний источник (например, бесплатный API ЦБ РФ), страна пребывания — по геолокации

- [ ] **Хранение ключей** — шифрование через Android Keystore
- [ ] **Изображение очков** — учесть правила Meta по использованию бренда в сторонних приложениях

- [ ] **Геолокация** — определение страны пребывания и список стран, где Яндекс Карты работают

## Приложение: текст пользовательского соглашения

Вставь текст в приложение без изменений. Значения в квадратных скобках я заполню перед публикацией.

### Пользовательское соглашение приложения «Sputnik — AI для очков»

Редакция 1.0 от [дата]

Пожалуйста, прочитайте это соглашение до конца. Оно короткое, но важное: в нём сказано, для чего предназначено приложение, какие риски вы принимаете на себя, за что отвечаете вы и за что — разработчик.
